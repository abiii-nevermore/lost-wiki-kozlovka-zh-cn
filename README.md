# lost-wiki-kozlovka-zh-cn
Lost Wiki: Kozlovka 简体中文汉化补丁
Lost Wiki: Kozlovka 简体中文补丁 v1.2 BETA 使用须知

【安装方法】
1. 退出游戏。如果安装过旧版汉化，请先通过 Steam“验证游戏文件完整性”恢复官方文件。
2. 将本补丁中的全部文件及 payload 文件夹放入 Lost Wiki Kozlovka.exe 所在目录。
3. 双击 install_beta.bat，提示安装成功后启动游戏，在语言菜单中选择“简体中文”。

【本版修复】
• 修复 Wiki 正文滚动时覆盖标题及“早期版本修改”提示的问题。
• 恢复报告正文的上下滚动，避免长报告将“提交调查”按钮挤出窗口。
• 保留当前官方其他语言与更新内容。

【备份与卸载】
安装时会自动备份原版 EXE。请保留生成的 .zh-v12.original.bak 和 .zh-v12.json 文件。
需要卸载时，退出游戏并双击 uninstall_beta.bat。

【游戏更新后】
本补丁采用资源级安装方式，不再依赖整个 EXE 的 xdelta 差分。
但这不代表兼容所有未来版本：若官方修改了补丁涉及的资源，安装器会停止安装并提示具体路径，请等待适配，不要强行覆盖。
如果游戏更新后无法卸载旧补丁，请使用 Steam“验证游戏文件完整性”恢复官方文件，避免用旧备份覆盖新版。

【问题反馈】
遇到安装失败、文字显示异常或界面问题，请提供：
• 完整报错或问题截图；
• 出问题的词条名称、报告位置；
• 游戏版本及补丁版本。

本补丁仅供已拥有正版游戏的玩家使用，不包含完整游戏。属于非官方汉化，与游戏开发者及发行商无关联。
